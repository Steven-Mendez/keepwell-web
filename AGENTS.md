# Keepwell web: notes for agents

Everything above this heading is regenerated by `next dev`; add Keepwell notes only below it. More
detail in [`README.md`](README.md).

## Commands

```bash
pnpm install
pnpm dev                                # http://localhost:3000
pnpm check                              # typecheck, lint, tests and shared:check; run it before calling a change done
pnpm test tests/domain/budgets.test.ts  # one test file (TZ=America/Managua, like iOS)
pnpm shared:check                       # the shared domain still compiles alone, the way keepwell-api copies it
pnpm tokens:check                       # design tokens still match keepwell-ios (needs ../keepwell-ios)
```

From a git worktree, point the tokens at the iOS checkout: `pnpm tokens:check --ios <path to keepwell-ios>`.

## The domain lives in three places

`src/lib/domain`, `src/lib/schema` and `src/lib/fixtures` are the source of the rules that
`keepwell-api` copies literally (with `i18n/translate.ts`, `strings.json`, `web-strings*.ts` and
`presentation/{display,notification-copy}.ts`; see "The shared domain" in `keepwell-api/README.md`)
and that `keepwell-ios` implements in Swift (`Packages/Domain`). A domain change goes:

1. Here first, with its tests in `tests/domain`, keeping these folders free of React, Dexie and
   anything but `zod` and `decimal.js` (`pnpm shared:check` fails otherwise).
2. Copied to the API with the README's commands; the copy is never edited by hand.
3. Ported to Swift with the same tests.
4. If the case fits `src/lib/fixtures/entities.json`, it goes there too: that file runs in all three suites.

Money is exact `Decimal` text with an ISO 4217 code: never floating point, never a sum of two currencies.

## Texts

Every visible text exists in English and Spanish and goes through the translator
(`t.in("<namespace>", "<English key>")`), never a literal in JSX. `src/lib/i18n/strings.json` is a
copy of the iOS `Localizable.xcstrings` catalogs: a text the iPhone app also shows is added in iOS
(English key) and copied here, not invented here. Desktop-only texts go in
`src/lib/i18n/web-strings*.ts`, with both languages. `tests/i18n.test.ts` fails when a screen uses a
key that exists in neither.
